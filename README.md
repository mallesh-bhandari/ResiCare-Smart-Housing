# ResiCare - Smart Housing Management System

A web-based housing management application designed to handle operational data, user management, and resident records.

## Key Features
* **Database Management:** Designed and structured MySQL database schemas for fast query retrieval and clean data handling.
* **Backend Workflows:** Built REST-based endpoints using Python and Flask for record management.
* **Containerization:** Configured Docker environment to ensure deployment consistency across systems.

## Tech Stack
* **Language:** Python
* **Backend Framework:** Flask
* **Database:** MySQL
* **Tools:** Docker, Git, HTML/CSS
